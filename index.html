Rity WHOOP 隐私政策

最后更新：2026-09-24

1. 应用说明

Rity WHOOP 是个人自用的健康数据应用，用于连接 WHOOP 官方 API。

2. 我们收集的数据

通过 WHOOP 官方 API 读取的只读健康数据，包括：恢复（Recovery，含恢复分数、心率变异性、静息心率）、睡眠（Sleep，含时长与起止时间）、每日 Strain（Cycles）、运动记录（Workout）、个人资料（Profile）、身体数据（Body Measurement，如身高、体重、最大心率）。本应用仅读取数据，不修改你的 WHOOP 账号中的任何内容。

3. 数据用途

数据仅用于个人健康监测：由用户的个人 AI 助手读取数据，提供中文解读与持续跟进。不用于任何其他目的。

4. 数据存储

OAuth 授权令牌保存在用户自己的 Muse 个人环境中，不上传到其他服务器。

5. 数据共享

我们不会与任何第三方共享、出售或出租你的数据。

6. 撤销授权

你可以随时在 WHOOP 账号或 App 设置中撤销本应用的授权。撤销后，本应用将无法再读取你的数据。
